# Practicum_projects
Тестирование приложения «Яндекс Самокат»: артефакты, автотесты и анализ интеграций

Репозиторий содержит материалы по комплексному тестированию сервиса аренды самокатов, включая тестирование фронтенда, мобильного приложения курьера, API и интеграционного взаимодействия между системами.

Что реализовано:

Тестирование вёрстки и UX: проверка отображения главной страницы лендинга, полей формы заказа и мобильного приложения курьера; выявление несоответствий макетам и проблем адаптивности.
Функциональное тестирование пользовательских сценариев: старт и завершение поездки, оформление заказа, валидация полей, отображение и изменение статусов заказа после бронирования и ответа курьера.
API‑тестирование: проверка запросов и ответов в Postman, анализ кодов состояния и структуры данных, валидация соответствия документации.
Анализ сетевого взаимодействия и эмуляция ответов: подмена ответов сервера через Charles Proxy для проверки обработки разных сценариев, включая ошибки и нестандартные статусы.
Инструменты диагностики: использование DevTools для анализа запросов, ошибок JS, сетевых задержек и заголовков.
Артефакты тестирования: тест‑кейсы, чек‑листы, баг‑репорты с шагами воспроизведения и скриншотами.
Стек и инструменты: Postman, Charles Proxy, DevTools, мобильные устройства для тестирования нативных приложений.

Цель проекта: систематизировать тестовые артефакты, обеспечить воспроизводимость проверок и прозрачность найденных дефектов для команды.
